## 三分钟体验路径

1. 打开产品，点示例“经营改善、估值合理、走势相对稳定”→「解析意图」。
2. 看左侧「AI 理解」：每个短语的口径与澄清选项（可切换）；右侧条件表可直接改阈值。
3. 「执行筛选」（沪深300，首次约 30–60 秒，之后有缓存）→ 看入选 / 排除 / 数据缺失三个列表，点任意股票看逐条件证据（接口、字段、request_id、数据时点）。
4. 「条件影响」页：哪个条件卡掉最多、去掉它会多几只、改阈值后新增/移除了谁。
5. 「数据口径与时点」页：每个数据集的状态与时点。
6. 展开「异常演示」勾选“模拟估值接口失败”再执行：依赖估值的条件变为“缺失”，股票进入“数据缺失”而不是“入选”。
7. 输入“明天哪只股票会涨？”：合规拦截。
8. 结果页可继续比较、保存、回测、转为监控。

## 与题目要求的对应

| 要求 | 实现 |
|---|---|
| 意图澄清、结构化条件、冲突识别与条件修改 | 模糊词澄清卡片；可编辑条件表；确定性冲突检测（矛盾阻止执行）+ AI 语义冲突提示；一句话修改生成变更清单需确认 |
| AI / 确定性引擎 / 数据工具职责边界 | README §2、DESIGN §1；AI 只输出目录内条件草案与基于证据的文案，判定只由引擎完成 |
| 入选/排除依据、数据口径、时点、缺失条件 | 每条判定带数值、阈值、分位与参考组、报告期或价格窗口、来源接口与字段、request_id、时点；缺失与不适用单独成桶并写原因 |
| 比较、保存、回测、监控 | 均已实现（回测按时点一致原则，含成本、基准与局限说明） |
| 关键数字可追溯 | `scripts/verify_traceability.py` 绕过产品直接重取原始字段比对；估算市值另用 iFinD 总市值交叉核验 |
| 数据缺失/接口失败不静默 | 故障注入演示、数据集 partial/failed 状态、受影响条件告警；缺失绝不判为通过 |
| 合规边界 | 输入侧拦截预测/荐股/收益承诺，输出侧清洗禁语，AI 文本数字校验，全站免责声明 |
| 不提交 Key 与受限数据 | Key 只在本地 `.env` 与部署平台环境变量；仓库无任何原始供应商数据，测试只用合成数据 |
